# 노티패널 (NotiPanel)

화면 위 투명 터치 아이콘을 누르면, 블러 배경의 알림 패널이 아이콘 위치에서 왼쪽 위로 펼쳐지는 앱.

## 기능
- 다른 앱 위에 떠 있는 터치 아이콘 (끌어서 이동 가능)
- 아이콘 불투명도 0~100%, 크기, 패널 블러 강도 설정
- 패널: 실제 알림 목록, 위아래 스크롤, 좌우로 밀어서 삭제, 눌러서 열기, 모두 지우기
- 패널 바깥 누르기 / 뒤로가기로 닫기
- 재부팅 후 자동 실행

## 빌드
GitHub에 올리면 Actions가 자동으로 APK를 빌드한다.
Actions 탭 → 최신 실행 → 하단 Artifacts의 `NotiPanel-apk` 다운로드.

## 처음 실행
1. 설정 화면에서 "다른 앱 위에 표시" 허용
2. "알림 접근" 허용
3. "터치 아이콘 켜기"
